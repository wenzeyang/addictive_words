# 预装统一词库数据库

技能随包提供 `assets/lexicons/tagged-vocabulary-v15.json.gz`。它由当前软件的统一转换词库生成，只保存抽词所需的词头与多标签归属，不复制词典例句。数据库共 22,960 个词条；同一词条可以同时带多个词库标签。

初始化前，如果本轮尚未明确且不是仅双语模式，必须询问用户是否剔除人教版初中和人教小学词汇。选择“剔除”时采用标签全局减法：任何词只要带 `pep-junior` 或 `pep-primary`，就从所有选中词库结果中排除，不能因它还带四级、雅思等标签而保留。选择“保留”时不启用这项减法。答案记录在 `pep_basic_policy` 与 `excluded_lexicons`，续作沿用。

默认选取全部 17 个标签的并集。用户可以指定其中任意标签子集；不要把“预装可用”误写成“本次全部选中”。旧项目中的一行一词自定义词表仍受支持，但新项目优先使用统一数据库。

匹配以显式词元为依据，同时核对它与英文实际词形的关系。脚本支持常见屈折变化和少量明确英美拼写对应；未识别的真实词形先查证再维护映射，不通过改词元或伪造说明绕过检查。`unaware` 不因 `aware` 命中而自动命中；`bladed` 也不因 `blade` 命中就被当作本义单词。

一项学习单元可以有多个目标词。至少一个目标词真实命中即可保留完整单元，辅助词无需都入表。导出时保留目标词命中的全部已选标签，不称整条短语或具体义项为官方考纲内容。原句和搭配来自本次译文或用户给定英文；标签命中不能代替用法审校。
