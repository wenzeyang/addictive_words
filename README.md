# 上瘾单词（Addictive Words）

仓库同时保留两份可离线运行的版本：

- `software/`：纯软件版，不含预置书本正文；保留 TXT 导入、词库筛选、随读词卡、挑战模式、复习、备份和本地语音回退等功能。
- `trial/`：内容试读版，仅保留指定试读书目，完整清单见 [`trial/README.md`](trial/README.md)。

直接打开对应目录中的 `index.html`。如果浏览器限制本地文件访问，请在该目录启动静态 HTTP 服务。
